# Site de contact Bambaa — version corrigée

Fichiers : index.html, styles.css, script.js, config.js, favicon.svg.

Le site conserve les services, le formulaire dynamique, les brouillons de formulaire, les fenêtres modales et l'envoi préparé sur WhatsApp. La section À propos et les liens vers le portfolio ont été retirés. La section Contact contient uniquement des boutons.

Dans config.js, vérifie le numéro WhatsApp, l'adresse Gmail et les liens sociaux avant de publier. Les coordonnées sont utilisées pour générer les liens, mais ne sont pas affichées dans la section Contact.

Déploiement : décompresse le ZIP puis glisse le dossier contenant index.html sur Netlify (déploiement manuel).
